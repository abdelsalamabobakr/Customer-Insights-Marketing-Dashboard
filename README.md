# 📈 Customer Insights & Marketing Analytics Dashboard

An interactive analytics dashboard designed to analyze customer demographics, purchasing behavior, marketing campaign efficiency, and sales channel effectiveness.

---

## 📊 Key Performance Indicators (KPIs)
* **Total Customers:** 2.236K
* **Total Revenue:** $27M
* **Avg Customer Income:** $52.23K
* **Avg Customer Spending:** $605.44
* **Campaign Response Rate:** 14.85%
* **Complaint Rate:** 0.94%

---

## 🔍 Key Dashboard Features

* **Category Spending:** Highlighting top-performing product categories like **Wines ($13.59M)** and **Meat Products ($7.46M)**.
* **Customer Behavior:** Analyzing the correlation between **Income vs. Total Spending**.
* **Marketing Campaigns:** Tracking performance across multiple campaigns (Campaign 4 & Campaign 3/5 leading response rates).
* **Channel Distribution:** Revenue breakdown across web, catalog, and store channels.
* **Interactive Filtering:** Slicers for **Education**, **Marital Status**, **Age Group**, and **Campaign Response**.

---

## 🛠️ Tools Used
* **Business Intelligence:** Power BI
* **Data Transformation:** Power Query / DAX
